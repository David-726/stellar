## **pcb错误**
### **引脚错误**
gemini生成的许多引脚并不对应实际的引脚，需要手动修改
 | 错误引脚 | 对应功能|
 | :--: | :--: |
 | PWM_MOT1 | PA9 |
 | PWM_MOT4 | PA27 |
 | I2C_SDA | PB9 |
 | I2C_SCL | PB8 |
 | CAN_TX | PB6 |
 | CAN_RX | PB7 |
 | UART2_TX | PB10 |
 | UART2_RX | PB11 |
 | PWM_FL | PA27 |
 | PWM_BR | PA9 |
