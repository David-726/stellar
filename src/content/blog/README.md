# 24_E三子棋实现方案

本项目为 2024 年电赛 E 题（三子棋对弈机器人）的完整系统实现方案。系统基于“视觉防抖识别 + Minimax 算法决策 + HMI 交互 + 闭环步进电机控制”构建。

## 2. 系统架构与职责划分

本系统采用严格的解耦架构，各司其职，通过串口总线进行状态同步：

- **上位机视觉决策大脑 (RaspberryPi_AI)**：
    
    - **视觉处理**：透视变换动态拉正棋盘，提取 HSV 亮度信息识别黑白子。
        
    - **AI 决策**：采用 Minimax (极大极小值) 算法，计算最优落子点。
        
    - **纠错监控**：利用“官方记忆库”核对机制，检测棋子非法位移。
        
- **下位机控制中枢 (STM32_Project)**：
    
    - **多任务调度**：基于 FreeRTOS 消息队列，防止高频指令覆盖死机。
        
    - **动作流水线**：解析坐标，驱动步进电机完成移动、吸取、归位等动作。
        
- **人机交互终端 (HMI_Project)**：
    
    - **状态托管**：利用串口屏局部变量前置逻辑，减轻单片机通讯负担。

## 3. 系统核心工作流 (Workflows)

### 3.1 正常对弈状态流转

代码段

```
sequenceDiagram
    participant HMI as HMI串口屏
    participant MCU as STM32 (分拣中心)
    participant Arm as 机械臂/电机
    participant Pi as 树莓派 (AI视觉)

    HMI->>MCU: 0x06 人类下黑子 (开启AI)
    MCU->>Arm: 下达取黑子任务
    MCU->>Pi: 透传 0x06 唤醒AI
    Note over Pi: 开启【视觉锁】暂停识别
    Note over Pi: 更新记忆并计算 Minimax
    Pi->>MCU: 0x01 发送机器白子最优解
    MCU->>Arm: 下达取白子任务
    Arm-->>MCU: 白子放置完成，归位
    MCU->>HMI: 更新屏幕位置为白子图片
    MCU->>Pi: 0x03 发送动作完成回执
    Note over Pi: 解除【视觉锁】，恢复监控
```

### 3.2 满分项：视觉防篡改与移位复原机制

代码段

```
graph TD
    A[画面稳定超15帧] --> B{对比'官方记忆库'}
    B -- 一致 --> C[继续待命监控]
    B -- 发现白子丢失 --> D[锁定丢失位置 Missing_ID]
    D --> E{全盘搜索多出的白子}

    H --> I[STM32：前往 Missing_ID 放回原处]
```

## 4. 三机串行通讯总线协议 (V1.0)

本系统内部通讯采用统一的十六进制定长/变长包格式，波特率统一为 **115200**。

### 4.1 通用帧结构 (Frame Structure)

|**字节 0**|**字节 1**|**字节 2**|**字节 3 ~ N**|**字节 N+1**|**字节 N+2**|
|---|---|---|---|---|---|
|**包头**|**功能码**|**数据长度**|**有效载荷 (Payload)**|**校验和**|**包尾**|
|`0xAA`|`CMD`|`LEN`|`Data...`|`SUM`|`0xFF`|

> **校验和规则**：`SUM = (CMD + LEN + sum(Data)) & 0xFF`，取累加和的低 8 位。

### 4.2 核心指令字典 (Command Dictionary)

- **🎮 [0x06] 玩家落子/触屏指令 (HMI ➔ STM32)**
    
    - **Payload**: `[ID(1-9)]` + `[类型(0x10黑/0x20白)]` + `[AI开关(0x01开/0x00关)]`
        
- **🤖 [0x01] 机器落子指令 (Pi ➔ STM32)**
    
    - **Payload**: `[目标格子 ID (0x01 - 0x09)]`
        
- **🚨 [0x08] 移位复原指令 (Pi ➔ STM32)**
    
    - **Payload**: `[错误位 ID]` + `[正确位 ID]`
        
- **✅ [0x03] 动作回执指令 (STM32 ➔ Pi)**
    
    - **Payload**: `[已完成动作的格子 ID]`
        
- **🗺️ [0x05] 动态地图标定 (Pi ➔ STM32)**
    
    - **Payload**: `[ID]` + `[X高8位]` + `[X低8位]` + `[Y高8位]` + `[Y低8位]`
        
- **🎛️ [0x10] 系统物理微调 (PC/HMI ➔ STM32)**
    
    - **Payload**: `[轴(0/1)]` + `[方向(0/1)]` + `[步进高8位]` + `[步进低8位]`

## 5. 联调与测试顺序

为保证模块稳定耦合，请按以下顺序调试：

1. **取子区标定**：使用串口助手发送 `0x10` 指令，测出取子区绝对脉冲并填入代码。
    
2. **20分序列盲操**：HMI 关闭 AI，手动测试黑白子放置路径。
    
3. **视觉闭环测试**：树莓派按 `c` 标定九宫格，开启 AI 模式进行对弈。
    
4. **10分纠错检验**：落子稳定后手动移开棋子，验证 `0x08` 协议。
