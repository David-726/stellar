# 串口高级解析与匹配模板

## 💣 踩坑记录
之前用 `sscanf` 直接读，遇到空格就断流，而且处理密码这种带特殊字符的很容易越界死机。

## 💡 核心解法
使用 **指针偏移** + `strncmp` 判断头 + `sscanf` 提取参数。

## 💻 考场默写代码
```c
void UART_Process(void) 
{
    char *buf = (char *)rx_buf;
    
    // 1. 设置时间指令 - TIME:235950
    if (strncmp(buf, "TIME:", 5) == 0) 
    {
        int h, m, s;
        if (sscanf(buf + 5, "%2d%2d%2d", &h, &m, &s) == 3) 
        {
            RTC_TimeTypeDef sTime = {h, m, s};
            HAL_RTC_SetTime(&hrtc, &sTime, RTC_FORMAT_BIN);
            HAL_UART_Transmit(&huart1, (uint8_t *)"OK\r\n", 4, 50);
        }
    }
    
    // 每次处理完必须清空缓冲区
    memset(rx_buf, 0, sizeof(rx_buf));
}
```

## ⚠️ 避坑 Checklist
- [ ] 串口接收数组 `rx_buf` 开得够不够大？
- [ ] 解析带 `%` 的占空比时，`sscanf` 里写成 `%%` 了没？
- [ ] 判断指令长度时，`strncmp` 的第 3 个参数（长度）数对了没（包含冒号）？
