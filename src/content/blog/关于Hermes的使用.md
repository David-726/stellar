**极其帅气的Tui**
```
hermes --tui
```
重要的命令：

|                       |           |
| --------------------- | --------- |
| `/help`               | 显示所有可用命令  |
| `/tools`              | 列出可用工具    |
| `/model`              | 交互式切换模型   |
| `/personality pirate` | 尝试一个有趣的人格 |
| `/save`               | 保存对话      |
|                       |           |
```
hermes --continue
hermes --resume <session_id>
```
